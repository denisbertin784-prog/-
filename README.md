# Stock Rustique

Application web statique (en français) pour gérer un stock simple avec :

- Ajout de produits (nom, catégorie, prix)
- Enregistrement des achats et des ventes
- Mise à jour automatique des quantités en stock
- Tableau de bord (produits, unités, ventes, achats)
- Historique des mouvements
- Sauvegarde locale via `localStorage`

## Lancer en local

```bash
python3 -m http.server 4173
```

Puis ouvrez <http://localhost:4173>.
